# structural-alloy-sdl-workshop

Planning materials for a workshop on **self-driving laboratories (SDLs) for
structural alloys**.

## Contents

- [`FUNDERS.md`](./FUNDERS.md) — catalog of potential funding sources (NSF, DOE,
  DOD, NASA, NIST, foundations, industry, and open-source-software sustainability
  programs such as NSF PESOSE) and guidance for identifying the current cognizant
  program officers / program managers.
